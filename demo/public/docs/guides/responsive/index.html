Responsive layouts

The layout follows the container width. Here is how to control what it does at each size.

How the width is measured

The width of the layout container (100% of its parent) is read on mount and again on ResizeObserver notifications, window resize and visibilitychange. The extra listeners keep the layout correct when the window was resized while the tab was in the background. The state is only updated when the width actually changed.

The parent must therefore have a real width. A hidden parent (display: none) renders nothing until it is shown.

Waterfall: by width limits

With minColumnWidth and maxColumnWidth the column count follows the width, see how the column count is chosen. This works well when you only need columns of a sensible size.

Waterfall: columns per breakpoint

When a design asks for an exact number of columns at specific widths, compute it yourself and pass columns:

TSX
import { useEffect, useState } from "react";

function useColumns() {
  const [columns, setColumns] = useState(2);
  useEffect(() => {
    const update = () => {
      const w = window.innerWidth;
      setColumns(w >= 1600 ? 6 : w >= 1280 ? 5 : w >= 992 ? 4 : w >= 640 ? 3 : 2);
    };
    update();
    window.addEventListener("resize", update);
    return () => window.removeEventListener("resize", update);
  }, []);
  return columns;
}

function Gallery() {
  const columns = useColumns();
  return <VirtualMasonry columns={columns} gap={16} loadData={loadData} renderItem={renderCard} />;
}

The same works for waterfallConfig={{ columns }} in DynamicMasonryView.

Equal-height rows

The equal-height layout has no column count: rows are rebuilt for every width by the same rule, so the number of images per row changes by itself. Adjust the look per breakpoint by passing different targetRowHeight and sizeRange, for example smaller rows on phones:

TSX
const small = window.innerWidth < 640;

<FullWidthEqualHeightMasonry
  targetRowHeight={small ? 140 : 245}
  sizeRange={small ? [120, 170] : [230, 260]}
  gap={small ? 4 : 8}
  loadData={loadData}
  renderItem={renderCard}
/>

Cost of resizing

Every width change recomputes the layout of all loaded items. It is cheap for thousands of items, but avoid changing gap, columns or size options on every animation frame.
