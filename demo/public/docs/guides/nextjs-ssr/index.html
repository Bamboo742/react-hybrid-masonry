Next.js and server-side rendering

What works on the server, what is deferred to the browser and how to hand over a prefetched first page.

Add the use client directive

The components use React hooks and are published without a directive. In the Next.js App Router import them from a client file:

"use client";

import { VirtualMasonry } from "react-hybrid-masonry";

export default function Gallery({ first }: { first: { items: any[]; hasMore: boolean } }) {
  return (
    <VirtualMasonry
      initialItems={first.items}
      initialHasMore={first.hasMore}
      loadData={(page, size) => fetch("/api/images?page=" + page + "&size=" + size).then((r) => r.json())}
      renderItem={(item) => <Card item={item} />}
    />
  );
}

Hand over a prefetched first page

Fetch page 1 in a server component and pass it as initialItems. The component then starts with that data, does not show the loading state and does not request page 1 again; the first loadData call is for page 2.

// app/gallery/page.tsx (server component)
import Gallery from "./Gallery";

export default async function Page() {
  const res = await fetch("https://api.example.com/images?page=1&size=30");
  const first = await res.json();
  return <Gallery first={{ items: first.items, hasMore: first.hasMore }} />;
}
initialItems is available on VirtualMasonry. DynamicMasonryView and FullWidthEqualHeightMasonry load their first page on the client.

Hydration is safe

Layout effects use useLayoutEffect in the browser and fall back to useEffect on the server. The container width is unknown during the server render, so the first render is an empty container on both sides and there is no hydration mismatch. Positions are computed right after mount, once the width is measured.

What the server HTML contains

Because positions depend on the measured width, the server HTML does not contain the cards, even with initialItems. If search engines must see the content, additionally render a crawlable list (for example links in the page, or a <noscript> block) next to the layout, or keep this gallery for content that does not need to be indexed.

Loading it lazily

The layout is only useful in the browser, so it can be split out of the initial bundle:

import dynamic from "next/dynamic";

const Gallery = dynamic(() => import("./Gallery"), { ssr: false });

Use this only when you do not need initialItems to avoid a loading flash.
