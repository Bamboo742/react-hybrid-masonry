How the equal-height layout works

The row-filling algorithm, step by step. Useful when you tune maxStretchRatio and sizeRange.

Input

Every item has an aspect ratio r = width / height. Using the target row height H, the ideal width of an item is r * H. W is the container width and g the gap.

1. Build a row greedily

Start a row with the next image. Before adding another image, compute the scale needed to make the current row fill the container:

Text
scale = (W - (n - 1) * g) / sum(r_i * H)   // n images in the row
  • If scale <= maxStretchRatio, the row is full enough: close it.
  • Otherwise add the next image and test again. Adding an image always brings the scale closer to 1.
  • If the row already needs to shrink (scale < 1) it is closed as well, with no limit on shrinking.

Because one image almost always needs a large enlargement to fill a row, this rule produces rows of at least two images without a special case.

2. Compute and clamp the row height

Text
rowHeight = H * scale
rowHeight = clamp(rowHeight, minHeight, maxHeight)   // sizeRange

sizeRange is an independent visual density limit, so it is always applied. When the clamp prevents an exact fill, the next step makes the row end at the edge anyway.

3. Distribute widths without drift

Each image gets r_i * rowHeight as its ideal width. To make the row end exactly at the container edge, the right edge of image i is computed from the cumulative share of the ideal widths, then rounded:

Text
available = W - (n - 1) * g
rightEdge_i = (sum(ideal_0..i) / sum(ideal_all)) * available + i * g
width_i     = round(rightEdge_i - x_i)

Rounding errors therefore never accumulate and are not pushed onto the last image, whose proportions would otherwise differ visibly from its real picture. Every width is then capped at maxItemWidth.

4. The last row

  • The row at the end of the loaded data is not stretched; its height is clamped between sizeRange[0] and targetRowHeight.
  • If its natural width would overflow the container, all of its images are scaled down by the same factor.
  • When another page arrives, the former last row becomes a normal row and is recomputed.

5. Virtualization

Each item gets x, y, width, height and originalIndex. Only items that intersect the viewport extended by buffer are rendered, using the item's originalIndex as the React key. The total height minHeight of the container is the bottom of the last row.

Tuning hints

  • Many rows with 2 images means a large targetRowHeight for the container width: lower it or widen sizeRange.
  • A very narrow sizeRange makes rows exact but allows only a few combinations; widen it if rows look uneven.
  • Lower maxStretchRatio for less enlargement, raise it to close rows earlier.
