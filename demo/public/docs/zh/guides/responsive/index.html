响应式布局

布局会跟随容器宽度。这里介绍如何控制它在各个尺寸下的表现。

宽度如何测量

布局容器（父元素宽度的 100%）的宽度会在挂载时读取一次，之后在 ResizeObserver 通知、窗口 resize 和 visibilitychange 时再读取。多出来的监听用于保证窗口在标签页处于后台时被缩放后，布局依然正确。只有宽度真的变化时才会更新状态。

所以父元素必须有真实宽度。被隐藏的父元素（display: none）在显示出来之前什么也不会渲染。

瀑布流：按宽度限制

设置 minColumnWidth 和 maxColumnWidth 后，列数随宽度变化，规则见列数如何确定。只需要大小合适的列时，这样就够用了。

瀑布流：按断点指定列数

当设计稿要求在特定宽度下是精确的列数时，请自己计算并传入 columns：

import { useEffect, useState } from "react";

function useColumns() {
  const [columns, setColumns] = useState(2);
  useEffect(() => {
    const update = () => {
      const w = window.innerWidth;
      setColumns(w >= 1600 ? 6 : w >= 1280 ? 5 : w >= 992 ? 4 : w >= 640 ? 3 : 2);
    };
    update();
    window.addEventListener("resize", update);
    return () => window.removeEventListener("resize", update);
  }, []);
  return columns;
}

function Gallery() {
  const columns = useColumns();
  return <VirtualMasonry columns={columns} gap={16} loadData={loadData} renderItem={renderCard} />;
}

DynamicMasonryView 里同样可以用 waterfallConfig={{ columns }}。

等高布局

等高布局没有列数的概念：每次宽度变化，各行都会按同一规则重新拼出，所以每行的图片数量会自动变化。想按断点调整观感，可以传入不同的 targetRowHeight 和 sizeRange，比如手机上用更小的行高：

const small = window.innerWidth < 640;

<FullWidthEqualHeightMasonry
  targetRowHeight={small ? 140 : 245}
  sizeRange={small ? [120, 170] : [230, 260]}
  gap={small ? 4 : 8}
  loadData={loadData}
  renderItem={renderCard}
/>

缩放的代价

每次宽度变化都会重新计算所有已加载元素的布局。几千个元素时开销很小，但不要在每一帧动画里都去修改 gap、columns 或尺寸参数。
