VirtualMasonry

Pinterest 风格的瀑布流布局：列宽相同，元素保持宽高比，放进当前最短的一列。只渲染视口附近的元素。

用法

TSX
import { VirtualMasonry } from "react-hybrid-masonry";

<VirtualMasonry
  loadData={loadData}
  pageSize={30}
  minColumnWidth={200}
  maxColumnWidth={350}
  gap={16}
  renderItem={(item) => (
    <div
      style={{
        position: "absolute",
        left: item.x,
        top: item.y,
        width: item.width,
        height: item.height,
      }}
    >
      <img src={item.url} alt={item.title} style={{ width: "100%", height: "100%", objectFit: "cover" }} />
    </div>
  )}
/>

属性

属性类型默认值说明
loadData(page, pageSize) => Promise<{ data: any[]; hasMore: boolean }>–加载一页数据，页码从 1 开始。不传则组件保持为空。
renderItem(item, index) => ReactNode必填渲染单个元素。index 是它在当前已渲染元素中的序号。
pageSizenumber50每页请求的数据量。
minColumnWidthnumber200最小列宽（px）。推算出的列数不会让列宽比它更窄。
maxColumnWidthnumber–最大列宽（px）。
columnsnumber–直接指定列数，不再按宽度推算。
gapnumber16元素之间的水平和垂直间距（px）。
buffernumber1500视口上下仍会渲染的缓冲距离（px）。
loadMoreThresholdnumber800距离底部多远（px）时开始请求下一页。
mapSize(raw) => { width, height }–把你的数据映射成宽高，见数据约定。
initialItemsany[]–已经拿到的第一页数据（如 SSR 预取）。传入后不会再请求第 1 页，下一次从第 2 页开始。
initialHasMorebooleantrue配合 initialItems，表示首屏之后是否还有更多数据。
enableAnimationbooleantrue预留参数，目前没有效果。

列数如何确定

  1. 设置了 columns 就直接使用它。
  2. 否则使用 floor(容器宽度 / minColumnWidth) 列，至少 1 列。
  3. 如果设置了 maxColumnWidth，而列宽超过了它，就逐列增加（最多 20 列）直到不超过；但如果再加一列会让列宽小于 minColumnWidth，就不再增加。两个限制无法同时满足时，以最小列宽为准。

列宽为 (容器宽度 - gap * (列数 - 1)) / 列数，并以 maxColumnWidth 为上限。上限生效时，网格是靠左排列的，右侧留空。

元素高度为 列宽 * (原始高度 / 原始宽度)，放进当前最矮的那一列。

示例

固定列数

TSX
<VirtualMasonry columns={4} gap={12} loadData={loadData} renderItem={renderCard} />

按断点选择列数可以用一个小 hook，见响应式布局。

从已有数据开始

TSX
<VirtualMasonry
  initialItems={firstPage.items}
  initialHasMore={firstPage.hasMore}
  loadData={loadData} // 第一次调用请求的是第 2 页
  renderItem={renderCard}
/>

尺寸在其他字段里

TSX
<VirtualMasonry
  mapSize={(raw) => ({ width: raw.imgW, height: raw.imgH })}
  loadData={loadData}
  renderItem={renderCard}
/>
