React Hybrid Masonry 使用文档

零依赖的 React 组件库，提供虚拟滚动的瀑布流（Masonry）与等高布局，支持无限滚动，并可由接口决定使用哪一种布局。

特性

  • 虚拟滚动：只渲染视口附近的元素，超长列表依然流畅。
  • 瀑布流布局：Pinterest 风格，每个元素放进当前最短的一列。
  • 等高布局：Google Photos 风格，每行高度一致，保持每张图片的原始比例。
  • 动态布局：由第一次接口返回的数据决定使用哪种布局。
  • 无限滚动：基于 IntersectionObserver，预加载距离可配置，同一时间只会有一个翻页请求在途。
  • 响应式：监听容器宽度，宽度变化时重新计算列和行。
  • TypeScript 编写，只对 React 16.8 及以上有 peer 依赖，没有其他依赖。

安装

npm install react-hybrid-masonry
# 或
yarn add react-hybrid-masonry
# 或
pnpm add react-hybrid-masonry

快速开始

三个组件的约定一致：loadData(page, pageSize) 返回 { data, hasMore }，每条数据都有宽和高，renderItem 把元素画在库算好的位置上。

import { VirtualMasonry } from "react-hybrid-masonry";

export function Gallery() {
  const loadData = async (page: number, pageSize: number) => {
    const res = await fetch("/api/images?page=" + page + "&size=" + pageSize);
    const json = await res.json();
    return { data: json.items, hasMore: json.hasMore };
  };

  return (
    <VirtualMasonry
      loadData={loadData}
      pageSize={30}
      minColumnWidth={200}
      maxColumnWidth={350}
      gap={16}
      renderItem={(item) => (
        <div key={item.id} style={{ position: "absolute", left: item.x, top: item.y, width: item.width, height: item.height }}>
          <img src={item.url} alt={item.title} style={{ width: "100%", height: "100%" }} />
        </div>
      )}
    />
  );
}

该用哪个组件？

组件布局适用场景
VirtualMasonry瀑布流：列宽相同，元素高度各异图片墙、商品流、高度不一的卡片
FullWidthEqualHeightMasonry每行等高并铺满整行宽度相册、时间线、以图片为主的搜索结果
DynamicMasonryView运行时在两者之间选择由后端或内容决定列表展示形式的场景

数据约定

组件需要在图片加载之前就知道每个元素的尺寸，才能算出它的位置。尺寸依次读取第一组存在的字段：width/height、w/h、imgW/imgH。其他结构请用 mapSize：

<VirtualMasonry
  mapSize={(raw) => ({ width: raw.cover.w, height: raw.cover.h })}
  /* ... */
/>

传给 renderItem 的每个 item 是你的原始对象，加上计算出的 x、y、width、height（以及 widthRatio）。你自己的字段，如 url、title，都会保留。

渲染约定

  • renderItem 返回的根元素必须使用绝对定位，并带上传入的 left、top、width、height。
  • 在这个元素上设置稳定的 key（如 item.id）。瀑布流布局里 index 参数只统计当前已渲染的元素，滚动时会变化。
  • 组件跟随 window 滚动，不是在内部容器里滚动，详见常见问题。
