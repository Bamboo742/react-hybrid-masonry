FullWidthEqualHeightMasonry

Google Photos 风格布局：图片保持宽高比，每一行高度相同，并按容器宽度精确拉伸或收缩来铺满。

用法

TSX
import { FullWidthEqualHeightMasonry } from "react-hybrid-masonry";

<FullWidthEqualHeightMasonry
  loadData={loadData}
  pageSize={30}
  targetRowHeight={245}
  sizeRange={[230, 260]}
  maxItemWidth={975}
  gap={8}
  renderItem={(item) => (
    <div
      style={{
        position: "absolute",
        left: item.x,
        top: item.y,
        width: item.width,
        height: item.height,
      }}
    >
      <img src={item.url} alt={item.title} style={{ width: "100%", height: "100%", objectFit: "cover" }} />
    </div>
  )}
/>

属性

属性类型默认值说明
loadData(page, pageSize) => Promise<{ data: any[]; hasMore: boolean }>–加载一页数据，页码从 1 开始。
renderItem(item, index) => ReactNode必填渲染单个已定位的元素。index 是它在全部已加载数据中的序号。
pageSizenumber50每页请求的数据量。
targetRowHeightnumber245目标行高，实际行高会在 sizeRange 内调整。
sizeRange[number, number][230, 260]允许的行高范围 [最小, 最大]。
maxItemWidthnumber975单个元素的最大宽度。
maxStretchRationumber1.5一行会不断加入新图片，直到填满整行所需的放大倍数不超过该值；缩小不设上限。
gapnumber8元素之间的水平和垂直间距（px）。
buffernumber1500视口周围仍会渲染的缓冲距离（px）。
loadMoreThresholdnumber500距离底部多远（px）时开始请求下一页。
mapSize(raw) => { width, height }–把你的数据映射成宽高。
enableAnimationbooleantrue预留参数，目前没有效果。

行为说明

  • 行是贪心地拼出来的：只要填满当前这一行所需的放大倍数超过 maxStretchRatio，就继续加入图片；需要缩小时则不限制缩小的幅度。
  • 行高随后被限制在 sizeRange 内，宽度再按比例分配，使整行刚好结束在容器边缘，不会把舍入误差留给最后一张图。
  • 最后一行不会被拉伸，保持自然比例（高度最多为 targetRowHeight），图片很少时不会被放大。下一页到来后，这一行会重新计算。
  • 任何元素都不会比 maxItemWidth 更宽，所以很宽的全景图不会占满整行。

完整流程见等高布局算法详解。

调参建议

目标做法
图片更大，每行更少提高 targetRowHeight 和 sizeRange，例如 320 和 [300, 360]。
对齐更严格缩小 sizeRange；此时每行靠选择不同的图片数量来铺满，而不是靠缩放。
避免行被明显放大把 maxStretchRatio 降到 1.2 左右；一行会放进更多图片后才结束。
避免超大的全景图降低 maxItemWidth。
