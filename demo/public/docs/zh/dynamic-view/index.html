DynamicMasonryView

一个组件，两种布局。布局由属性、第一次接口返回或默认值决定。

三种确定布局的方式

1. 受控

<DynamicMasonryView
  isMasonry={useWaterfall} // true = 瀑布流，false = 等高布局
  loadData={loadData}
  renderItem={(item, index, isMasonry) => /* ... */ null}
/>

该属性优先级最高。它变化时，当前布局会被重新挂载，并从第 1 页重新加载。

2. 由第一次接口返回决定

<DynamicMasonryView
  loadData={async (page, pageSize) => {
    const res = await fetch("/api/content?page=" + page + "&size=" + pageSize);
    const json = await res.json();
    return page === 1
      ? { data: json.items, hasMore: json.hasMore, isMasonry: json.layoutType === "waterfall" }
      : { data: json.items, hasMore: json.hasMore };
  }}
  renderItem={(item, index, isMasonry) => /* ... */ null}
/>

组件挂载时调用一次 loadData(1, pageSize)，从结果里读取 isMasonry，并缓存这第一页数据，所以选好的布局会立刻展示它，第 1 页不会被请求第二次。布局类型只读取一次，后续页不需要再返回。

3. 默认值

如果 loadData 没有返回 isMasonry，则使用 defaultIsMasonry（默认 true）。如果第一次请求失败，会调用 onError 并使用默认布局。

属性

属性类型默认值说明
isMasonryboolean–受控模式。true 为瀑布流，false 为等高布局。
defaultIsMasonrybooleantrueloadData 没有返回 isMasonry 时使用。
loadDataLoadDataFn–(page, pageSize) => Promise<{ data, hasMore, isMasonry? }>。
renderItem(item, index, isMasonry) => ReactNode必填渲染函数，最后一个参数表示当前使用的布局。
waterfallConfig{ minColumnWidth, maxColumnWidth, columns, gap, buffer }{}传给 VirtualMasonry。
equalHeightConfig{ targetRowHeight, sizeRange, maxItemWidth, maxStretchRatio, gap, buffer }{}传给 FullWidthEqualHeightMasonry。
pageSizenumber50每页请求的数据量。
mapSize(raw) => { width, height }–把你的数据映射成宽高。
renderInitialLoader() => ReactNode空白块确定布局类型之前显示的内容。
onLayoutTypeLoaded(isMasonry: boolean) => void–布局类型确定后调用。
onError(error: Error) => void–第一次请求失败时调用。
enableAnimationbooleantrue预留参数，目前没有效果。

导出的类型

import {
  DynamicMasonryView,
  ViewType, // 枚举：ViewType.Waterfall = 1，ViewType.EqualHeight = 2
} from "react-hybrid-masonry";
import type { DynamicMasonryViewProps, LoadDataFn } from "react-hybrid-masonry";
